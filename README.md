# Vector2-UnityProject
Vector 2 Unity project originally by Sonamenil

Vector 2 project was created by Sonamenil, but this is a fork of his work, with the ability to load custom rooms and textures as a runtime. 

I am aware of the security issues with this version. Consider using the Unity patching tool to fix the issue. 


Sonamenils original project: https://github.com/sonamenil/Vector2-UnityProject

Unity Patching tool: https://discussions.unity.com/t/cve-2025-59489-patcher-tool/1688032

Side note, if you install the unity project, the main menu scene is called main
